# Web Development Projects

This repository contains two beginner-friendly web projects built using HTML, CSS, and JavaScript.

## 1. Calculator
- Performs addition, subtraction, multiplication, and division.
- Includes a clear/reset button.
- Provides a simple, user-friendly interface.

## 2. Digital Clock
- Displays the current hour, minutes, and seconds.
- Shows AM/PM.
- Updates automatically every second.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run
- Open `index.html` in the root folder to run the Calculator.
- Open `digital-time/index.html` to run the Digital Clock.
